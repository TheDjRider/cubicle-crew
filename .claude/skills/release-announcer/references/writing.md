# Writing the posts

## Voice

The author is Kalin, a solo developer sharing a fun side project: Claude Code agents as
little pixel-art coworkers in an office. The tone is warm, a bit playful, concrete, and
never corporate. Show, don't hype: "the cats now chase the dart that misses the board"
beats "exciting new features". No "🚀 Thrilled to announce", no wall of hashtags, no
claims that aren't in the changes.

Write in the language set in the config per platform (default English). The app itself
supports English and Bulgarian, which is worth mentioning to a Bulgarian audience.

Always:
- name the version (e.g. v1.4.0)
- 2–4 concrete changes a user would notice
- one link: the release page if there's a download, otherwise the repo
- which media is attached
- the disclaimer is not needed in posts, but never imply Anthropic made or endorses it

## LinkedIn

Hook line (what's new, in human terms) → 2–3 short lines or a small list of changes →
one line on why it exists (seeing at a glance which agent is busy, stuck or waiting on
you) → link → 3–5 relevant hashtags at the end (#ClaudeCode #AIagents #pixelart
#opensource #buildinpublic). 600–1,200 characters is the sweet spot.

## X

One punchy line + the single most visual change + link + GIF/video. Max two hashtags.
If there's more to say, a thread of 2–3 posts: 1) hook + media, 2) other changes,
3) link + "it's open source, MIT".

## Facebook

Friendlier and more personal than LinkedIn; can be a short story ("my agents got a
new …"). Medium length, link at the end, no hashtags or one at most.

## Reddit

Title: plain and specific, e.g. "I made my Claude Code agents into pixel-art
coworkers — v1.4 adds weather in the windows and a third cat". No clickbait, no emoji
spam.

Body: who you are in one line → what it does in 2 lines (for people who haven't seen
it) → what's new in this version → how to try it (link, `npm start` or the Windows
installer) → an honest question asking for feedback or ideas. Mention it's free / MIT
and that it only reads local files (Reddit will ask).
