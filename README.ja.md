### Claude Code のエージェントが、小さなピクセルアートのオフィスで働きます。

[English](README.md) · **日本語** · [简体中文](README.zh-CN.md)

Claude Code のセッションはひとつずつ、デスクに座る同僚になります。**Codex**、**Gemini CLI**、**OpenCode** のセッションも同じです。**Copilot CLI、Cursor、自作スクリプト**も小さなローカル API（[docs/api.md](docs/api.md)、英語）から参加できます。サブエージェントはドアから入ってきてタスクを受け取り、チームの席に着きます。誰かがあなたを待っていれば、部屋全体がそれを知らせます。

## なぜ作ったのか

Claude Code は、複数のセッションを同時に動かし、サブエージェントに仕事を任せるときに一番力を発揮します。ただ、ターミナルのタブが積み重なると状況が追いにくくなります。まだ作業中なのは誰か、質問で止まっているのは誰か、10 分前に黙って終わっていたのは誰か。

Cubicle Crew は Claude Code がもともと `~/.claude/projects` に書き出しているセッションログを読み、それを生きたシーンに変えます。セカンドモニターに開いておくことも、ウィジェットとして画面の隅に置いておくこともできます。

- **ひと目ですべての状態がわかります。** シャツ、モニターの光、名札の色が、そのエージェントがしていることを表します。
- **委任が目に見えます。** オーケストレーターはサブエージェントのところまで歩いて書類を渡します。床の点線が誰が誰のために働いているかを示します。
- **質問を見逃しません。** あなたを待っているエージェント（`AskUserQuestion` や「Allow Bash?」の許可プロンプト）は手を振り、名札が赤く点滅して「Allow Bash?」と表示されます。別のウィンドウを見ているときは小さなチャイムが鳴り、デスクトップアプリは通知も出します。
- **設定は不要です。** API キーもフックのインストールもいりません。オフラインで動き、ローカルのファイルを読むだけです。

## 機能

| | |
|---|---|
| 🧑‍💻 **チーム** | ★ の名札が付いたリーダー席が 2 つと、その下にサブエージェント用のデスクが 3 つ。空いているデスクには、どのサブエージェントでも座れます。デスクがないサブエージェントは、空くまでソファでノート PC を使って作業します。チームごとにマグカップの色が違い、リーダーとサブエージェントは線で結ばれます。3 つ目のセッションは、リーダー席が空くまでラウンジで働きます。 |
| 🔌 **どのエージェントでも、エンドポイントはひとつ** | `POST http://127.0.0.1:4317/api/event`（ローカルのみ）で何でもオフィスに入れられます。**GitHub Copilot CLI** と **Cursor** 用のフック設定、Claude Code 形式のフックを持つエージェント、`curl` や `npx cubicle-crew event tool_start --agent build --tool Bash --detail "npm test"` を使うスクリプト。デスクに座り、現在のツールの吹き出しが出て、あなたを待つと赤くなり、終わると帰っていきます。[docs/api.md](docs/api.md) を参照してください。 |
| 📄 **デスクの上のコンテキスト** | 各デスクの紙の束は、エージェントのコンテキストウィンドウに合わせて高くなります。埋まってくると黄色、さらに赤い付箋が付き、会話が圧縮（compact）されると紙が机から飛んでいきます。カードには正確な数値が出ます。Claude Code、Codex、OpenCode に対応しています。 |
| ✅ **オフィスから許可 / 拒否** *（任意）* | `?` パネルで **Answer permission prompts here** をオンにすると、Claude Code の「Allow …?」がオフィス下部のバーに **Allow** と **Deny** のボタン付きで表示されます（キーは `Y` / `N`、デスクトップアプリではどのウィンドウからでも `Ctrl+Alt+Y` / `Ctrl+Alt+N`）。`~/.claude/settings.json` にフックを 1 つ追加し（バックアップを保存）、オフにすると削除します。ターミナルはそのまま使えます。45 秒以内にオフィスで答えなかった場合や、ターミナルで答えた場合は、ターミナル側は何も変わりません。 |
| ⚠️ **危険なコマンドは赤で** | 再帰的な削除、git 履歴の書き換え、本番環境に触れるシェルコマンド（`rm -rf`、`Remove-Item -Recurse -Force`、force push、`git reset --hard`、`terraform apply`、`kubectl delete`、`DROP TABLE`、`curl … \| sh`、「prod」を含むもの）は、吹き出し、カード、細いストリップ、許可バーで赤い ⚠ が付きます。許可する前にもう一度確認できます。 |
| 💥 **クラッシュしたセッション** | ツールの実行中に Claude Code のセッションが閉じた場合（クラッシュ、ターミナルの強制終了）、エージェントは黙って帰りません。ホバーかクリックするまで、「Session ended」の吹き出しを出したままグレーで席に残ります。 |
| 🎨 **7 つの状態** | `idle` · `thinking` · `typing` · `reading` · `running` · `delegating` · `waiting`。それぞれに専用のポーズ、モニター表示、パーティクルがあります。 |
| 🛋️ **ラウンジ** | 手の空いたセッションはコーヒーを取りに行き、ソファで携帯ゲームをしたり、居眠りしたり、ダーツをしたりします。ラウンジには最大 3 匹のペットがいます。毛柄の違う猫たちと、休んでいる人の隣に座りたがる犬（ビーグル、ゴールデン、コーギー、ハスキー、ダックスフント…）。ペットにホバーすると名前が出て、クリックすると名前を変えられます。 |
| 🌇 **本物の空** | 背の高いフランス窓は、あなたの街の時計（またはパソコンの時計）に合わせて変わります。夜明け、夕暮れ、夜。暗くなるとランプ、モニター、ネオンサインが光り、夕方には天井の照明が点きます。ドアの横のスイッチで消すこともできます。 |
| 🌧️ **本物の天気** *（任意）* | ショップの **Weather** タブで街を選ぶと（本棚の上の小さな気象ステーションをクリックしても可）、窓の外に実際の天気が映ります。雲、ガラスを伝う雨、窓枠に積もる雪、霧、稲妻。曇りの日は部屋が少し暗くなり、ステーションに気温と降水確率が出ます。データは 20 分ごとに [Open-Meteo](https://open-meteo.com) から取得し、送信されるのは街の座標だけです。街を選ぶまでは、アプリはインターネットに一切接続しません。 |
| 🪙 **コインとショップ** | 働いているエージェントはコインを稼ぎます。それを約 50 種類のインテリアに使えます。床、壁、ラグ、ソファ、リーダー用の玉座、ネオンサイン、水槽、アーケード筐体、猫の追加、犬とその犬種、9 種類の猫の毛柄。実績も 14 個あります。 |
| 🧍 **自分のアバター** | 自分のキャラクター（オフィスで最初のオーケストレーター）の性別、髪型、トップス（女性はスカート、ズボン、ワンピースも）、肌、髪の色、メガネを選べます。ほかの人はランダムです。 |
| 🧘 **フォーカスモードとプライバシー** | スイッチひとつ（`?` ボタンまたはトレイメニュー）で、コイン、ショップ、ペット、パーティクル、ゲームをすべてオフにして、誰が何をしているか、誰があなたを待っているかだけを表示します。**Hide commands and paths** は吹き出しをツール名だけにします。画面共有や配信向けです。`?` パネルではすべての状態の説明も見られ、各状態は色だけでなくドットの形でも区別できます。オーケストレーターをクリックすると、そのセッションに名前を付けられます。 |
| ↗️ **ターミナルへジャンプ** | エージェントをダブルクリックすると（カード、ストリップ、「あなたを待っています」通知からも可）、そのセッションが動いているウィンドウが前面に出ます。Windows Terminal、VS Code、JetBrains、Terminal.app、iTerm に対応しています。 |
| 📊 **統計** | 状態ごとの作業時間、エージェントがあなたを待った時間、ツール呼び出し数、トランスクリプトから取った実際のトークン使用量を、日別・プロジェクト別に表示します。Claude API の料金で計算した場合のコストも出ます（モデル別、キャッシュの読み書き込み。Pro/Max プランではトークン単位の支払いはありませんが、作業の価値の目安になります）。CSV/JSON でエクスポートでき、データはパソコンの中にだけ保存されます。ホワイトボードをクリックすると、リーダーの 1 人が歩いて行ってリモコンを向け、スクリーンが降りて今日の数字を発表します。もう一度クリックすると 7 日と 30 日の数字になります。エージェントをクリックすると、最近の操作も見られます。 |
| 🎬 **共有** | `?` パネルから、オフィスのくっきりした PNG スナップショットや 10 秒の MP4 クリップを作れます。`?overlay` を付けると、コマンドとパスを隠した OBS ブラウザソース向けのシーンになります。 |
| 🎃 **季節の飾りとペット** | 秋はカボチャ、クリスマスはツリー、春はチューリップ、夏は扇風機。売られるのはその季節だけですが、一度買えばずっと使えます。ペットはクリックするとなでられます。 |
| 🐧 **WSL、Docker、Cowork** | Windows では、起動中の WSL ディストリビューション内の `~/.claude/projects` も監視します。Docker や VM の中の Claude Code も、その `~/.claude` をフォルダーにマウントして設定に追加すれば表示されます（[手順](docs/docker.md)、英語）。Claude Desktop の Cowork タスクは自動で見つかります。 |
| 🔔 **サウンド** | エージェントがあなたを必要としたとき（質問や許可プロンプト）は 8 ビットの「ピンポン」、1 分以上の作業のあとにセッションが終わると短いファンファーレ。別のウィンドウを見ているときだけ鳴り、下のバーのベル（またはトレイメニュー）でミュートできます。ブラウザでは、ページを最初にクリックしたあとから鳴ります。 |
| 🖥️ **デスクトップウィジェット** | タスクトレイの上に浮かぶ、枠なしで常に最前面の Windows アプリ。トレイメニュー、`Ctrl+Alt+P`、通知、Windows と同時に起動。 |
| 🧩 **改造できるアート** | すべてコードで描かれていますが、コードに触れずに自分の PNG キャラクターシートやタイルセットに置き換えられます。 |

## クイックスタート

**Node.js 18 以上**が必要です。インストール不要で、一番早い方法はブラウザで開くことです。

```bash
npx cubicle-crew     # → http://localhost:4317   (--demo, --port 4400, --no-open)
```

ソースから動かす場合：

```bash
git clone https://github.com/rezored/cubicle-crew.git
cd cubicle-crew
npm install
npm start            # → http://localhost:4317
```

ポート `4317` がほかのプログラムに使われている場合（OpenTelemetry Collector のデフォルトポートでもあります）、サーバーは `4318`〜`4320` を使い、実際のアドレスをコンソールに表示します。`4317` ではなくコンソールの URL を開いてください。`PORT=` で固定することもできます。

初回は短いセットアップで、オフィスで飼うのが猫か犬か（とその名前）、時計と天気のためにどの街にいるかを聞かれます。どちらもスキップでき、あとからショップで変更できます。

あとはどこかで Claude Code のセッションを始めるだけです。同僚がドアから入ってきます。

セッションがない場合は、**[rezored.github.io/cubicle-crew](https://rezored.github.io/cubicle-crew/)** で同じシミュレーションが動いています（架空のエージェントで、何もインストールせず、何も読み取りません）。ローカルではほかにもあります。

| URL | 内容 |
|---|---|
| `/?demo` | ライブシミュレーション：2 チームの委任、出入りするセッション、すべての状態 |
| `/?demo=showcase` | 2 チーム、待機中の 2 セッション、7 つの状態を一度に見せる固定シーン（スクリーンショット向け） |
| `/?demo&agents=1` | オーケストレーター 1 人だけのシミュレーション |
| `/?time=22:30` | 時計をごまかして夜のオフィスを見る |
| `/?debug` | FPS、レイアウト情報、最新イベントのログ |
| `/?atlas=6` | 生成されたキャラクタースプライトを 6 倍で一覧表示 |

環境変数：`PORT`（デフォルト `4317`）、`CLAUDE_PROJECTS_DIR`（デフォルト `~/.claude/projects`）、`CLAUDE_SESSIONS_DIR`、`PIXEL_OFFICE_HOME`（セーブファイルの場所、デフォルト `~/.pixel-office`）。`npm run debug` は解析したすべてのイベントと、各サブエージェントが親にどう結び付けられたかを表示します。

**操作：** キャラクターにホバーすると詳細、クリックでフォーカス（スポットライトと情報カード）。`L` で凡例の表示切り替え、`B` でショップ、`Esc` でフォーカス解除。

**言語：** 英語またはブルガリア語。システムの言語に合わせます。切り替えは HUD の `EN`/`БГ` チップ、URL の `?lang=en` / `?lang=bg`、デスクトップアプリのトレイメニューから。

## デスクトップウィジェット（Windows）

**一番簡単な方法：** [最新リリース](https://github.com/rezored/cubicle-crew/releases/latest) から `CubicleCrew-Setup-<version>.exe` をダウンロードして実行します。

インストーラーはコード署名されていません（Cubicle Crew は無料の個人プロジェクトです）。そのため初回は Windows が **「Windows によって PC が保護されました」** と表示することがあります。**詳細情報** をクリックし、**実行** を選んでください。このリポジトリのリリースと同じファイルです。アプリが読む・書く・送るものはすべて [docs/security.md](docs/security.md)（英語）に書かれています。

ソースから：

```bash
npm run desktop      # Electron アプリをソースから実行
npm run dist         # インストーラーをビルド → release/CubicleCrew-Setup-<version>.exe
```

ウィジェットは自分でサーバーを動かすので、ブラウザや `npm start` は不要です。右下のタスクトレイの上に表示され、ほかのウィンドウより常に手前にあります。ホバーするとドラッグ用のバーが出て、設定、ピン留め、クリックスルー、非表示、終了のボタンがあります。`Ctrl+Alt+P` でどこからでも表示・非表示を切り替えられます。トレイメニューには、通知、サウンド、Windows と同時に起動、デモモード、サイズのリセットがあります。

インストール版はデフォルトで Windows と同時に起動します。起動時にまだ Claude Code のセッションがなければ、トレイの上の小さなウィンドウで朝のシーン（コーヒーを持ったアバター、窓辺で眠るペット、実際の時刻の空）を表示して待ちます。セッションが現れるか、クリックすると、オフィス全体が開きます。最後のセッションが閉じて 1 分経つと、小さなウィンドウに戻ります。どちらもトレイメニューの **Start with Windows** と **Small window until the first session** でオフにできます。

## デスクトップウィジェット（macOS）

macOS 13 Ventura 以降が必要です。一番簡単なのは Homebrew です。

```bash
brew install --cask rezored/tap/cubicle-crew
```

下の追加のセキュリティ手順なしで開けます（cask が隔離フラグを外します）。更新は `brew upgrade --cask cubicle-crew` です。

または [最新リリース](https://github.com/rezored/cubicle-crew/releases/latest) から `CubicleCrew-<version>-mac.dmg` をダウンロードし（Apple Silicon と Intel 共通のビルド）、開いて **Cubicle Crew** を「アプリケーション」にドラッグします。

アプリはまだ Apple Developer ID で署名されていないため、`.dmg` からの初回起動には手順がひとつ必要です。アプリを右クリック → **開く** → **開く**。macOS 15 以降では、一度開いてから **システム設定 → プライバシーとセキュリティ → このまま開く** を選びます。「壊れている」と表示された場合は、一度だけ `xattr -cr "/Applications/Cubicle Crew.app"` を実行してください。

Mac ではウィジェットはメニューバーに常駐し（Dock アイコンなし）、メニューバーの下の右上に開き、すべてのデスクトップに表示されます。メニューの **Start at login** にチェックを入れない限り、ログイン時には起動しません。`⌘⌥P` で表示・非表示を切り替えます。通知、ストリップ、フォーカスモード、ターミナルへのジャンプ（Terminal、iTerm、VS Code…）は Windows と同じように動きます。

## デスクトップウィジェット（Linux）

[最新リリース](https://github.com/rezored/cubicle-crew/releases/latest) から `CubicleCrew-<version>-linux.AppImage` をダウンロードし、実行権限を付けて（`chmod +x`）起動します。ターミナルへのジャンプとログイン時の起動は Linux ではまだ対応していませんが、それ以外は Windows と同じです。トレイアイコンにはトレイ対応のデスクトップが必要です（GNOME では AppIndicator 拡張機能）。

## 設定

設定はすべてウィンドウ内の **設定パネル** にあります。下のバーの `?` ボタン、`?` キー、アプリのタイトルバーの ⚙ ボタン、またはトレイメニューの **Settings and help…** から開けます。6 つのセクション（Look、Alerts、Privacy & data、Window、Share、Help）があり、すべての項目に一行の説明が付いています。項目の一覧は [英語版 README](README.md#settings) を参照してください。

## 仕組み

すべてはあなたのマシンの中で完結します。アプリが読む・書く・送るものは [docs/security.md](docs/security.md)（英語）に正確に書かれています。

```
~/.claude/projects/**/*.jsonl  ──tail──▶  server.js  ──WebSocket──▶  ブラウザ / Electron
~/.claude/sessions/<pid>.json  ──poll──▶     │                         │
~/.codex/sessions/**/*.jsonl   ──tail──▶     │
~/.gemini/tmp/*/chats/*.jsonl  ──tail──▶     │
opencode.db（読み取り専用）    ──poll──▶     │
                                         wallet.js                  canvas のシーン
                                  (~/.pixel-office/save.json)     (vanilla ES modules)
```

- **サーバー**（`server.js`）：直近 1 時間に更新されたトランスクリプトを監視し、各行を小さなイベント（`tool_start`、`tool_end`、`say`、`user_prompt`）に変換します。サブエージェントは、まず `subagents/agent-<id>.meta.json`、次にセッション ID、最後にタイミングから親に結び付けます。また毎秒 `~/.claude/sessions` を読み、どのセッションがまだ開いているか、作業中か、あなたを待っているかを把握します。起動時に過去の履歴は再生しません。
- **Codex、Gemini CLI、OpenCode**（`providers.js`）：Codex のロールアウトファイルと Gemini CLI のチャットログは、Claude Code のトランスクリプトと同じように監視します（Gemini のサブエージェントはサブエージェントとして入ってきます）。シェルコマンドは読み取り（`rg`、`cat`、`Get-Content`…）と実行に分類し、`apply_patch` は typing になります。OpenCode の SQLite データベースは毎秒 1 回、読み取り専用で読みます。ラベルには `· Codex` / `· Gemini` / `· OpenCode` が付きます。これらにはライブセッションのファイルがないため、許可プロンプトで赤くなることはまだなく、ターミナルへのジャンプも Claude Code だけです。
- **ツール → 状態：** `Edit`/`Write` → typing、`Read`/`Grep`/`WebFetch` → reading、`Bash` → running、`Task`/`Agent` → delegating、`AskUserQuestion` → waiting。8 秒間何もなければ idle になりますが、Claude Code がセッションを作業中と報告している間（考えている、長い返答を書いている）は別です。対応は `public/rules.js` で変更できます。
- **許可プロンプト** はトランスクリプトには記録されませんが、画面に表示されている間、Claude Code はセッションを `waiting`（`waitingFor: "permission prompt"`）にします。最後にツールを開始したエージェントが、答えるまで赤くなり、Allow をクリックした瞬間に作業に戻ります。
- **クライアント**（`public/`）：ビルド不要の素の ES モジュール。シーンは低解像度の canvas に描かれ、デバイスピクセルの整数倍で拡大されるので、どの DPI でもくっきり表示されます。文字はすべて canvas の上に重ねた HTML です。
- **コイン：** サーバー側で 5 秒ごとに加算されます。動いているオーケストレーター 1 分あたり約 1 枚、サブエージェントはその半分、タスク完了でボーナス。Cubicle Crew のウィンドウを複数開いていても、数えるのは 1 つだけです。セーブファイルはアトミックに書き込まれ、バックアップも保存されます。

## Pixel Agents との違い

[Pixel Agents](https://github.com/pixel-agents-hq/pixel-agents) は似たアイデアの素晴らしい VS Code 拡張機能です。Cubicle Crew は別の方向に進んでいます。

- **単独で動きます。** デスクトップウィジェットとして、またはどのブラウザでも、エディターやターミナルの横で動きます。VS Code は必要ありません。
- **小さな放置ゲームです。** エージェントがコインを稼ぎ、あなたは家具、ペット、インテリアに使います。実績とアバターもあります。
- **オフィスがあなたの環境全体に反応します。** セッションごとのチーム、2 つ以上のセッションが動くときのラウンジの待ち行列、ローカルの時計に合わせた昼と夜の空。
- **アセットゼロ。** スプライトも家具もすべてコードで描かれているので、買うものもダウンロードするものもありません。それでも自分のタイルセットを入れることはできます。
